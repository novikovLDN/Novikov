# Фаза 3 — дизайн-система «Гратикул»

Дата: 8 сентября 2026. Основание: `02_BRAND.md` (архетип — Хранитель с
оптикой Картографа), `01_RESEARCH.md`, требование ТЗ о светлом корпусе.

## 0. Откуда взята форма

Из предмета, а не из подборки. Atlas — свод карт; продукт измеряет
расстояния, задержки и полосу и наносит их на бумагу. Значит язык
системы — язык **навигационной карты**: холодная бумага, глубокие
морские чернила, размеченная координатная сетка, магента для
специальных зон (на настоящих морских картах ею печатают то, что
требует внимания), и **числа как главный типографический материал**.

Это даёт три вещи, которых нет у конкурентов: холодную, а не тёплую
бумагу; акцент, который в этой отрасли не занят; и сетку, которая
предъявлена и подписана, а не спрятана.

## 1. Цвет

### База — холодная бумага, не крем

```
--paper      #F2F4F3   основной фон: бумага с зелёно-серым подтоном
--paper-2    #E7EBEA   утопленная поверхность, полосы таблиц
--vellum     #FFFFFF   «освещённая» плоскость: карточка, поповер, панель
--line       #BCC7C6   линия сетки и границы (1,57:1 — не для текста)
--line-2     #94A2A2   активная граница, ось координат (2,39:1)
```

Чистый `#FFFFFF` не фон, а **материал**: им сделаны поднятые
плоскости. Разница между `--paper` и `--vellum` — единственный
источник глубины в системе, тень её только подтверждает.

### Чернила — глубокая морская, не «почти-чёрный»

```
--ink        #12262E   основной текст          14,16:1  AAA
--ink-2      #45585F   вторичный текст          6,76:1  AA
--ink-3      #5E7178   подписи, мета            4,63:1  AA
```

`#12262E` — не тонированный чёрный, а тёмная сине-зелёная. На бумаге с
тем же подтоном она читается как чернила, а не как «серый текст».

### Акцент — картографическая магента

```
--chart      #C10E6B   акцент: заливка, граница, точка      5,37:1  AA
--chart-deep #A00A58   акцент как цвет текста и ссылки      7,10:1  AAA
--chart-soft rgba(193, 14, 107, 0.10)   подложка
```

Магента выбрана по двум причинам: на бумажных морских картах ею
печатают зоны, требующие внимания, — то есть у цвета есть повод; и она
не занята в отрасли (Cloudflare — оранжевый, Selectel и NordVPN —
синий, Vercel — чёрный, Linear — фиолетово-серый, Mullvad —
жёлто-зелёный).

**Акцент как цвет текста — отдельный токен.** `--chart` даёт 5,37:1 и
формально проходит, но для 11–13px метки этого мало; ссылки и глифы
красятся `--chart-deep` (7,10:1). Это то же правило, что уже работало
в прежней системе, и его переносим.

### Состояние — не декор

```
--sounding   #0D6E64   измерено, подключено, оплачено       5,54:1  AA
--shoal      #B3541E   внимание, срок истекает              (проверить)
--rock       #A4161A   ошибка, отказ                        (проверить)
```

Цвета состояний **не используются как оформление**. Зелёного «просто
для красоты» в системе нет.

### Запрещено
Кремовый фон, терракота, кислотно-зелёный, «почти-чёрный» вместо
чёрного, градиентные заливки как украшение, второй акцент.

## 2. Типографика

### Выбор гарнитуры

Критерии из ТЗ (6.2): отличная кириллица, вариативные оси, лицензия
для коммерческого веба, выразительность в крупных кеглях. Плюс наш
собственный: **табличные цифры** — числа здесь несут смысл чаще, чем
слова.

**Основной путь (требует бюджета, `QUESTIONS.md` №16):**
Suisse Int'l или Graphik — нейтральные гротески с настоящей
кириллицей и регистром «институция». Обе платные.

**Путь без бюджета, работает сегодня:**
**Golos Text** (Paratype, свободная лицензия) — кириллица родная, а не
дорисованная; вариативная ось веса; спокойный характер без
характерных завитков. Одна гарнитура на всё.

**Чего не берём:** Inter, Roboto, Montserrat (запрет ТЗ), Oswald
(нынешний — узкий конденсед, читается как афиша, а не как институция),
Onest (нынешний текстовый — годен, но нейтрален до безликости).

### Одна гарнитура вместо трёх

Сейчас на первом экране три семейства (Oswald + Onest + JetBrains
Mono) — 196 КБ. Система переходит на **одно** с вариативной осью веса:
крупный заголовок берёт 700, текст 400, подпись 500 с увеличенным
трекингом.

**Моноширинного нет.** Он запрещён ТЗ (6.2) как «шрифт для
техничности» и назван типовым признаком сгенерированной страницы. Всё,
ради чего он стоял, — выравнивание чисел — делают табличные цифры
(`font-variant-numeric: tabular-nums`) той же гарнитуры.

### Шкала

Модульная, шаг 1,25 (мажорная терция), опорный кегль 17px.

```
--t-hero    clamp(3.2rem, 8.5vw, 8.5rem)   заголовок первого экрана
--t-scene   clamp(2.2rem, 5vw, 4.4rem)     заголовок сцены
--t-block   clamp(1.5rem, 2.6vw, 2.1rem)   заголовок блока
--t-lead    clamp(1.12rem, 1.5vw, 1.4rem)  лид
--t-body    1.0625rem                      основной текст (17px)
--t-small   0.9375rem                      подпись (15px)
--t-meta    0.8125rem                      мета (13px, не меньше)
```

11px из системы выведены: на светлой бумаге они не проходят порог даже
при исправленном цвете.

Интерлиньяж: заголовки 1,02–1,08; текст 1,55; мера строки — **не более
72 знаков**.

### Числа — материал

Задержка, полоса, цена, число стран набираются крупнее окружающего
текста, табличными цифрами, с отрицательным трекингом −0,02em. Это
основной приём системы: **на карте главное — измерение**.

### Нарушения правил, которые мы применяем намеренно

| Приём | Где допустим | Где запрещён |
|---|---|---|
| Заголовок выходит за колонку в поле карты | первый экран, финал | тарифы, формы |
| Число крупнее заголовка рядом с ним | цена, задержка, полоса | везде, где число не главное |
| Строка обрывается координатой сетки | сцена атласа | текстовые абзацы |
| Подпись стоит вертикально вдоль оси | легенда карты | навигация, кнопки |

### Чего в наборе не будет

Капслок-надзаголовков над каждым блоком; выделения одного слова цветом
в заголовке; «→» в тексте кнопок; служебных строк, склеенных
средними точками (`A · B · C`). Всё это было в прежней системе и всё
это — типовые признаки, а не решения.

## 3. Сетка — гратикул

Не 12 колонок, спрятанных под контентом, а **координатная сетка,
которая видна и подписана**, как на карте.

- Поле: 12 колонок, `--gutter: clamp(16px, 2.4vw, 32px)`,
  максимальная ширина 1560px.
- Линии сетки видны на `--line` при 1px и не исчезают: это часть
  оформления, а не отладочный слой.
- Меридианы подписаны по краю поля значением, которое имеет смысл на
  этой странице: на атласе — долготой, на цене — периодом, на
  конфигураторе — ступенью полосы.
- Контейнерные запросы вместо брейкпоинтов экрана там, где элемент
  живёт в разных колонках (карточка конфигурации, ячейка состава).

**Выравнивание.** Текст — по левому краю всегда; выключка по формату
на кириллице даёт дыры. Числа — по правому в таблицах, по левому в
карточках. Центрируется только финальный экран: единственное место,
где нет ничего, кроме одного действия.

## 4. Материал и глубина

Тени — многослойные и слабые, поднимают только то, что действительно
поднято:

```
--lift-1  0 1px 2px rgba(18,38,46,.06), 0 2px 8px rgba(18,38,46,.04)
--lift-2  0 2px 4px rgba(18,38,46,.07), 0 12px 28px rgba(18,38,46,.07)
--lift-3  0 8px 20px rgba(18,38,46,.10), 0 32px 64px rgba(18,38,46,.10)
```

Зерно — **текстура поверхности**, а не слой во весь экран: `--vellum`
получает едва заметный шум в собственном фоне. Слой во весь экран с
`mix-blend-mode` из системы выведен — замерено, что он заставляет
компоновщик пересобирать кадр постоянно.

Радиусы: **2px** на всём, кроме круглых индикаторов. Не ноль (нулевой
радиус вместе с волосяными линиями — типовой «широкоформатный» шаблон)
и не 12–16px (шаблон SaaS-карточек).

## 5. Моушн

```
--d-fast   140ms    отклик на действие
--d-base   280ms    смена состояния
--d-scene  700ms    смена сцены
--e-out    cubic-bezier(.2, .8, .2, 1)
--e-in-out cubic-bezier(.65, 0, .35, 1)
```

Правила:

1. **Один поставленный момент на страницу.** На главной — как
   вычерчивается карта при загрузке (изолинии проявляются от центра
   наружу за 900 мс, один раз). Больше нигде.
2. Всё остальное движение — **ответ на действие** человека.
3. Появление секций — нативное `animation-timeline: view()` там, где
   браузер понимает; никакого «fade-up у всего»: у блока меняется
   только непрозрачность, без сдвига.
4. Закреплённые сцены (scrub, pin) остаются на GSAP — нативно они не
   выражаются. У каждой обязан быть непрерывный признак прокрутки.
5. Пишутся только `transform`, `opacity` и CSS-переменные.
6. `prefers-reduced-motion` даёт осмысленную статику: сцена не
   закрепляется, содержимое стоит блоками.

## 6. Иконки и графика

Собственный набор, одна толщина линии 1,5px, прямые торцы, без
скруглений на концах. Сток запрещён (ТЗ 15.2).

Вся графика процедурная: карта присутствия точками из
`world-map.ts` (уже есть), изолинии полосы, схема пути пакета,
разрез стойки — SVG и canvas. 3D-сцена одна на сайт (глобус сети) и
грузится лениво, с фолбэком на статичный кадр.
