# ADR-0008. Без CMS: контент — типизированные модули

**Статус:** принято, 8 сентября 2026.

## Контекст
ТЗ (7.1) предлагает Payload или Sanity для блога, документации,
новостей и команды. Нужен ли блог и документация вообще — открытый
вопрос (`QUESTIONS.md` №18).

## Решение
CMS **не заводим** сейчас.

Причина не в экономии. Главная ценность бренда — «числа на сайте
подтверждены кодом» (`02_BRAND.md`). CMS открывает путь, которым
непроверенное утверждение попадает на страницу мимо
`COMPLIANCE-CHECK.md`. Пока не описан процесс проверки публикаций,
CMS — это риск для позиционирования, а не удобство.

Контент живёт типизированными модулями (`plans.ts`, `locations.ts`,
`servers.ts`, `faq.ts`), правки идут через репозиторий и ревью.

## Последствия
- Блог и документация — вне объёма до ответа владельца.
- Если CMS понадобится, к ней сразу пишется правило: числовое
  утверждение публикуется только вместе со строкой в
  `COMPLIANCE-CHECK.md`.
