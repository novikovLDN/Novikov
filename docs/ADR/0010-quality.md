# ADR-0010. CI, тесты, бюджеты

**Статус:** принято, 8 сентября 2026.

## Контекст
В репозитории нет `.github/workflows`. Тесты — только
`src/lib/__tests__`. Оплата и синхронизация с панелью не покрыты.
Регрессии ловятся руками; в этой сессии, например, чёрный текст на
чёрной карточке в кабинете прожил до тех пор, пока экран не открыли
глазами.

## Решение

**Конвейер на каждый PR:**
`lint → tsc → vitest → playwright → build → lighthouse-ci → превью`

- **Vitest** (обновить до 5.0.0): расчёт цены конфигурации,
  совместимость опций, переходы статусов заказа, идемпотентность
  вебхука.
- **Playwright** 1.63.0: подключение тарифа, сборка и оплата сервера
  с моком платёжки, отказ оплаты, повтор вебхука, смена языка, формы.
- **Lighthouse CI** с бюджетами из `03_DESIGN_SYSTEM.md`, раздел 7.
  Сборка падает при превышении.
- **axe-core** внутри Playwright.
- **Knip** — мёртвый код. В этой сессии нашлось 70 КБ неиспользуемого
  CSS и 14 осиротевших модулей; автоматика нашла бы их раньше.

**Визуальные регрессии.** Требуют флага, останавливающего живой слой:
сейчас страницы не отдают стабильный кадр никогда, и снимок не
снимается (`00_AUDIT.md`, раздел 5). Флаг `?static=1` вводится
вместе с новым моушн-слоем.

## Последствия
- Бюджет, не проверяемый машиной, не соблюдается — поэтому Lighthouse
  в конвейере, а не в отчёте.
- Сборка на машине разработчика перестаёт быть единственной проверкой.
