# ADR-0009. next-intl, локаль в маршруте

**Статус:** принято, 8 сентября 2026.

## Контекст
`src/lib/i18n.tsx` объявляет `Locale = "en" | "ru"`, но значение
жёстко задано `"ru"`: словарь есть, английской версии сайта нет.
ТЗ (5.3) требует ru + en с адаптацией, а не дословным переводом.

## Решение
next-intl 4.14.2, локаль сегментом пути (`/en/...`), `hreflang` и
`canonical` на каждой странице. Свой `I18nProvider` удаляется.

## Последствия
- Тексты берутся из `02_COPY.md`, где английский написан как
  адаптация.
- Числа, даты и валюты форматируются по локали
  (`Intl.NumberFormat`), а не строкой.
- Кто пишет английский для юридических страниц — открытый вопрос
  (`QUESTIONS.md` №13). До ответа `/en` их не показывает.
- Карта редиректов старых URL готовится вместе с переключением.
