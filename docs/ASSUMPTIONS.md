# Допущения и ограничения среды

Записаны по требованию ТЗ (раздел 0): всё, чего нет в исходных данных
или в доступе, фиксируется явно.

## Ограничения инструментов в этой сессии

| Что | Состояние | Обход |
|---|---|---|
| Figma MCP | подключён, но **не авторизован** | Дизайн-система описывается токенами в Markdown; макеты — ASCII-вайрфреймы |
| Генерация изображений / 3D | инструментов нет | Вся графика — процедурная: шейдеры, SVG, CSS, canvas. Совпадает с запретом ТЗ на сток |
| GitHub MCP | нет | PR и issues — через `gh` CLI |
| Скриншоты Playwright | **не работают на этом сайте** | Причина и пути обхода — `00_AUDIT.md`, раздел 5 |
| Веб-поиск | доступен | Используется в фазе 1 |
| Context7 | подключён | Актуальные API вместо памяти |
| Локальная БД | PostgreSQL не установлен, `.env` нет | Кабинет проверяется подменой ответа `/api/user/subscription` |

## Допущения по среде разработки

1. **Проект лежит на Рабочем столе, синхронизируемом с iCloud.**
   Наблюдалось: конфликтные копии в `.next` (`routes.d 14.ts`,
   `validator 27.ts`), `rm -rf .next` около 25 минут, dev-сервер
   отдавал старый CSS после правок, инкрементальная сборка дважды
   выдала манифест со ссылками на ненаписанные чанки. Все замеры в
   этой сессии сделаны на **чистой** сборке, поднятой с локального
   диска вне iCloud. Рекомендация: перенести репозиторий из `~/Desktop`.

2. **Прод — qodev.dev.** atlassecure.uk обслуживает сборку от 25 мая
   2026 и к текущему коду отношения не имеет.

3. **`CLAUDE.md` устарел в части цвета.** Он описывает светлую систему
   PIXEL, тогда как `brand.css` перекрашивает её в чернила. Если новое
   ТЗ утверждается, `CLAUDE.md` переписывается на фазе 3.
