# Инвентаризация анимаций

Дата: 8 сентября 2026. Ветка `redesign-2027`.

Клиенту нравится существующий моушн — значит, прежде чем что-то
менять, нужно понимать, **что именно** нравится. Ниже каждый приём с
техникой, триггером, оценкой и главное — почему он работает.

Общее правило слоя, которое стоит унаследовать: пишутся только
`transform`, `opacity` и CSS-переменные; слушатели пассивные; значение
считает rAF, а не рендер React; `prefers-reduced-motion` упрощает
слой, а не ломает его; состояния, которые прячут контент до скрипта,
объявляются под классом, который ставит сам скрипт.

## F. Точечные взаимодействия (`pixel/effects.tsx`)

`Magnetic` (кнопка тянется к курсору, одна на экран), `Scramble`,
`SplitText`, `SpotlightLayer` (один делегированный слушатель на
документ, а не ref в каждой карточке), `useTilt`, `useGridTorch`
(фонарик по сетке), `PixelTrail`, `PixelDissolve`, `useScrollScene`,
`useMouseLayer`, `usePixelBurst` (вспышка из точки нажатия, узлы
убираются по `animationend`).

Оценка: **сохранить механику, пересмотреть дозировку.** Правило уже
записано в проекте и его стоит унаследовать: магнитная кнопка — одна
на экран, раскодирование — только на коротких служебных метках,
наклон — на карточке-иллюстрации.

терминал ничего не заменяет.

## H. Что заменить

| Что | Почему |
|---|---|
| `dv2Rise` / `fadeInUp` / `.px-reveal` на каждой секции | Ровно тот «fade-up у всего», который ТЗ (15.7) запрещает. Заменить на режиссированный вход по сценам |
| Одинаковый hover-подъём у карточек `.dv2-card`, `.px-card` | Одинаковая реакция у всего = никакой реакции |
| `pulseGlow`, `gradientShift`, `shimmer`, `badgeGradient`, `confettiFall` в `globals.css` | Наследие прежних слоёв, к текущему языку отношения не имеют |
| Зерно во весь экран с `mix-blend-mode` и бесконечной анимацией | Заставляет компоновщик пересобирать кадр постоянно. Уже сведено к страницам бренда; в новой системе — решить осознанно |
