# Фаза C — структура и поэкранная партитура «Атлас-издание»

Дата: 10 сентября 2026. Основание: `CONCEPTS.md` (раздел «Утверждено
10.09.2026»), `A7_OTHER_NICHES.md`, `A8_CARTOGRAPHY_CULTURE.md`,
`ANIMATION_CATALOG.md`, `STACK_DECISION.md`.

Все числа в черновиках текста — шаблоны из кода: `{COUNTRY_COUNT}`,
`{TRIAL_DAYS}`, `{DEVICE_LIMIT}`, `{PLAN_SPEED.plus}`,
`{SERVER_ENTRY_USD}` и т.д. На сборке они подставляются из
`src/lib/*`, руками не пишутся. Ориентировочные значения
(`latencyMs` в `locations.ts`) везде подписаны «ориентировочно».

## 0. Сквозные правила

### 0.1 Информационная архитектура: сайт — атлас

Сайт — одно издание из пронумерованных листов, а не набор страниц.
Главная — сквозной маршрут через листы 01–08; остальные разделы —
отдельные листы того же атласа, с тем же полем и номером.

```
Выпуск: сентябрь 2026                                   масштаб 1 : 1
┌────────────────────────── ГЛАВНАЯ (маршрут) ─────────────────────────┐
│ 00 раскладка → 01 обложка → 02 одна и та же страница → 03 граница    │
│ → 04 девятнадцать стран → 05 легенда → 06 три шага → 07 указатель    │
│ → 08 финал                                                           │
└──────────────────────────────────────────────────────────────────────┘
Отдельные листы:  10 тарифы (/pricing)   11 выделенные серверы (/vds)
                  12 устройства (/devices) 13 для бизнеса  14 поддержка
                  15 контакты  16 безопасность  17 инфраструктура  18 о нас
                  19 лист страны (/locations/[code], новый)   ∅ 404 «белое пятно»
Выходные данные (футер) — на каждом листе.
```

Номер листа — постоянное свойство раздела (одна таблица в
`src/lib/nav.ts`), не порядковый номер на странице.

### 0.2 Обязательные блоки промта → что это у Atlas

| Блок промта | Лист | Как переизобретён |
|---|---|---|
| intro / preloader | 00 раскладка | прелоадера нет; первое посещение — развёртка листа по сгибам, 600 мс, поверх уже отрисованной страницы |
| hero-манифест | 01 обложка | два слова во всю ширину, кусок карты внутри строки, подпись-наблюдение к карте |
| кто мы | 03 граница | манифест бренда на плите: «называем границу» |
| услуги | 05 легенда | два продукта как легенда карты: условные знаки ускорителя и серверов |
| кейсы (как пространство) | 04 девятнадцать стран + 19 лист страны | карта присутствия с изохронами; кейс — лист страны |
| процесс | 06 три шага | маршрут с тремя подписанными остановками |
| команда | выходные данные | команды не выдумываем (ТЗ 15.5); вместо портретов — выходные данные издания: кто отвечает, год, адрес для писем |
| клиенты / цифры без счётчиков | 07 указатель | каталожная таблица всех чисел сайта с источником |
| контакт как объект | 15 контакты | «нанести точку»: письмо как отметка на листе |
| футер | выходные данные | колофон издания + указатель листов |
| 404 | ∅ белое пятно | «этот лист ещё не нанесён» |
| кейс-страница | 19 лист страны | новый маршрут, опционально (фаза D.2) |
| вакансии | — | не заводим: данных нет, выдумывать запрещено. Карточка в §4 на случай решения владельца |

### 0.3 Поле листа (глобальная раскладка)

- **Поле.** Сверху одна волосяная линия во всю ширину; пункты меню
  стоят на ней (Eladio Dieste, Franklin Azzi). Никакой стеклянной
  шапки, никакого `backdrop-filter`.
- **Углы.** Левый верхний — знак Atlas (форма из `BrandMark.tsx` не
  меняется). Правый верхний — «Лист 04 · *Девятнадцать стран*»,
  смешанная строка. Левый нижний — «Выпуск: сентябрь 2026» (дата
  сборки). Правый нижний — масштаб или «ориентировочно», если на
  листе оценки.
- **Сетка.** Модуль колонки один: `--gh-col` (4 / 8 / 12). Рваная
  посадка сцен сохраняется.
- **Мобильный.** Меню уходит в указатель листов (таблица на весь
  экран), вызывается номером листа в углу. Тап-зоны от 44 px.

### 0.4 Токены движения

| Токен | Значение | Где |
|---|---|---|
| `--m-pen` | `linear` | прочерчивание линий, край маски перелистывания |
| `--m-settle` | `cubic-bezier(0.2, 0, 0, 1)` | подписи ложатся, листы раскрываются |
| `--m-turn` | `cubic-bezier(0.65, 0, 0.35, 1)` | смена номера листа, инверсия по наведению |
| `--d-1` | 240 мс | отклик на руку, второй прогон (задержка) |
| `--d-2` | 480 мс | подпись, калька, второй прогон (посадка) |
| `--d-3` | 900 мс | перелистывание листа, потолок любого события |
| `--stagger` | 40 мс | подписи по `sibling-index()` / `--i` |

Пружин, отскоков и overshoot нет. Событие дольше 900 мс запрещено:
на сайте ускорителя медленный кинематограф не должен становиться
ожиданием.

### 0.5 Бюджет движения сайта

Замер `research/05_MOTION.md`: движение по прокрутке 491 при медиане
330. Цель редакции — 350–400, проверка тем же скриптом.

| Режим | Разрешено | Всего на главной |
|---|---|---|
| **Прокрутка (scrub)** | маршрут читателя (одна линия через всю главную); полосы листа 02; прочерчивание изохрон листа 04; горизонтальный ход легенды 05 на десктопе | **4 шкалы** (сейчас 49) |
| **Разовое по порогу** (`animation-trigger`, фолбэк — IntersectionObserver-класс) | М1 второй прогон у каждого листа; подписи ложатся | не ограничено, но каждое ≤ 900 мс |
| **Холостое** | 1) мигание живого показания; 2) медленный дрейф изохрон (фаза 60 с, только в кадре) | **2**, как сейчас |
| **Рука** | калька М3, вязкость = время ответа (A2), инверсия строки по наведению | свободнее, не входит в метрику прокрутки |
| **Переходы** | М2 перелистывание листа | одно на навигацию |

Требование Design Standard «каждый блок анимирован: load / scroll /
hover / idle, без исключений» спорит с замером (см.
`00_PHASE_A_REPORT.md`). В этой партитуре у каждого блока **определены**
все четыре состояния; где стоит «нет, намеренно», это решение с
причиной, а не пропуск. Формулировка ждёт утверждения владельцем.

### 0.6 Слой изображения сайта: один холст

Один Canvas 2D на сайт — «лист карты» (эволюция `SignalField`).
Рисует: штриховку суши по маске `world-map.ts` (гравюрный штрих
вместо точек), изохроны времени ответа, маршрут читателя. Потолок —
1400 штрихов в кадре (Walkable Atlas), ≤ 4 мс на кадр на среднем
телефоне; цикл встаёт вне кадра и в скрытой вкладке. Без скрипта и
при reduced-motion — статичный SVG того же листа, сгенерированный на
сборке. `SignalTrace` (FPS) с публичных листов уходит (A7 §6, п. 11).

WebGL, WebGPU и 3D-библиотек нет (`STACK_DECISION.md`, вариант «если
бюджет меньше» — здесь это не экономия, а решение направления).

### 0.7 Карточка блока — формат

Каждый блок ниже описан одинаково: цель · правило и нарушение ·
текст · партитура (load / scroll: enter–progress–exit / hover / idle /
click / transition-out) · слой изображения · мобильный · бюджет ·
a11y.

## 1. Главная — маршрут

### Лист 00 · *Раскладка* (intro)

**Цель.** Показать, что сайт — лист атласа, не заставив ждать ни
миллисекунды.

**Правило.** Страница отрисована сервером в конечном виде до любого
скрипта. **Нарушение.** При первом посещении за сессию поверх готовой
страницы проходит развёртка: две линии сгиба (вертикальная и
горизонтальная) расходятся от центра к краям, как раскрывается
сложенная карта. Контент под ними уже на месте и кликабелен.

**Текст.** Нет. В правом нижнем углу на время развёртки — «лист
раскладывается», затем подпись меняется на масштаб.

| Состояние | Партитура |
|---|---|
| load | 0 мс: страница видна. 80 мс: две линии сгиба `--a-ink` 1 px в центре, `scaleX/scaleY` от 0 до 1 за 600 мс `--m-pen`. 600 мс: линии гаснут `opacity` за 240 мс `--m-settle`. Итого 840 мс |
| scroll | нет, намеренно: интро не повторяется на прокрутке |
| hover | нет, намеренно: слой `pointer-events: none` |
| idle | нет |
| click | клик в любой момент прекращает развёртку (конечный кадр) |
| transition-out | нет |

**Слой изображения.** Нет, только два элемента DOM.

**Мобильный.** То же, линии по размеру окна. Флаг первого посещения —
`sessionStorage` в try/catch; без доступа развёртка не играется.

**Бюджет.** 0 КБ библиотек, 2 узла, только `transform` и `opacity`,
0 кадров в покое. Не влияет на LCP: элемент LCP — заголовок листа 01.

**A11y.** `aria-hidden` на линиях; при reduced-motion и на флаге
`?static=1` не создаётся.

### Лист 01 · *Обложка* (hero-манифест)

**Цель.** За три секунды: это атлас, и он про то, что интернет
работает одинаково отовсюду.

**Правило.** Две строки выключены по ширине колонки, каждая своим
кеглем (`100cqw / k`, `k` перемерить на Literata opsz 72 wght 300).
**Нарушение.** В строку подзаголовка между словами вставлен фрагмент
карты высотой в строчную букву: изохроны вокруг города читателя. Объект
первого экрана рождается из набора, а не стоит рядом (Paul
Kalkbrenner, The Watch).

**Текст (черновик).**

> одинаково
> отовсюду
>
> От *вашего города* [▭ фрагмент карты] до ближайшего сервера.
> VPS-ускоритель Atlas Secure: {COUNTRY_COUNT} стран, без просадок.
>
> [ {TRIAL_DAYS} дня бесплатно ]   Выделенные серверы
>
> *{дата}, {время}. {Город или «Москва, по умолчанию»}. До ближайшего
> сервера, в {CLOSEST.city} — {мс} мс{, ориентировочно}.*

Заголовок — строчными, Literata 300. Подпись внизу — курсивом, в
голосе натуралиста (Reed Hilderbrand: «Sep 2024, 83°F, Overcast
clouds»). Выносок «без оговорок» уходит: его роль — порвать
прямоугольник — берёт фрагмент карты.

Главное действие — инверсия (плита `--a-plate`, текст `--a-paper`).
Цвет в кадре только у фрагмента карты (синь) и у числа мс в подписи,
если оно замерено (киноварь). Оценка остаётся краской.

| Состояние | Партитура |
|---|---|
| load | Заголовок виден сразу (LCP). 0–600 мс: интро (лист 00). 200 мс: фрагмент карты — изохроны прочерчиваются от центра наружу, 5 линий × 120 мс `--m-pen`, стаггер 40 мс. 700 мс: подпись-наблюдение ложится `translateY(4px→0)` + `opacity` 480 мс `--m-settle`. Замер `LivePing` приходит — число мс меняется на месте (без прокрутки цифр) и получает киноварь |
| scroll enter | нет (лист уже в кадре) |
| scroll progress | начинается маршрут читателя: пунктир киноварью выходит из фрагмента карты и уходит по диагонали вниз вправо; длина = прогресс прокрутки главной (одна шкала `scroll(root)`) |
| scroll exit | заголовок не анимируется, уходит вместе с листом. Фрагмент карты остаётся в строке |
| hover | кнопка: инверсия на месте — плита ↔ бумага, 240 мс `--m-turn`. Фрагмент карты: курсор над ним — изохроны догоняют руку с постоянной времени = время ответа читателя (A2 «Вязкость», τ 8–400 мс) |
| idle | живое показание мигает (холостое №1, как сейчас) |
| click | «{TRIAL_DAYS} дня бесплатно» → М2 перелистывание на лист входа |
| transition-out | М2 (см. §3) |

**Слой изображения.** Фрагмент карты — вырезка того же единственного
холста (или SVG, если холст ещё не проснулся): ≤ 200 штрихов.

**Мобильный.** Две строки остаются выключенными (кегль по `cqw`).
Фрагмент карты переносится на отдельную строку под заголовком, во всю
ширину, высотой 3 строчных. Вязкость отвечает на касание и
перетаскивание пальцем. Гироскоп не используем: на iOS нужен запрос
разрешения, и первым же экраном сайт просил бы доступ к датчику.

**Бюджет.** LCP — текст h1, шрифт Literata дисплейный с урезанным
набором знаков, `preload`, `font-display: swap` c метрик-переопределением
(CLS 0). Холст: ≤ 200 штрихов, ≤ 2 мс/кадр. JS листа ≤ 6 КБ gz сверх
текущего. Кадр помещается в экран 900/800/844 по высоте (правило
CLAUDE.md сохраняется).

**A11y.** h1 — текст «одинаково отовсюду», фрагмент карты `aria-hidden`.
Подпись-наблюдение — `<p>`; обновление числа через `aria-live="polite"`
один раз, не на каждое мигание. Город без согласия не определяется.

### Лист 02 · *Одна и та же страница* (почему)

**Цель.** Показать разницу, которую человек знает по опыту: страница
висит — страница открылась.

**Правило.** Две дорожки одной длины, одна над другой, на модуле
колонки. **Нарушение.** Медленная дорожка распадается на блоки 8×8 и
смазывается вбок ступеньками, как зависший видеозвонок (A4
«Датамош»), и выходит за правое поле листа.

**Текст (черновик).**

> одна и та же страница
>
> без ускорителя ——————————— 61 % — *не отвечает*
> через Atlas   ——————————————————— готово, *{CLOSEST.city}*
>
> Atlas шифрует соединение и меняет страну выхода — и страница
> открывается оттуда, откуда открывается.
>
> [ как сейчас | через Atlas ]  ← калька

Исправлено: `готово · {город}` (`Home.tsx:188`) — мета-строка через
среднюю точку из AI-кластера №5 — становится смешанной строкой
«готово, *Минск*».

| Состояние | Партитура |
|---|---|
| load | базовое состояние без скрипта: медленная на 61 % с подписью «не отвечает», быстрая — полная |
| scroll enter | М1 второй прогон: контуры дорожек чёрным сразу, через 240 мс заливка быстрой дорожки синью со сдвигом приводки 3 px, садится в ноль за 480 мс |
| scroll progress | обе дорожки растут по шкале секции (одна шкала, существующий `--lap`). На 61 % медленная останавливается и распадается на 12–16 плиток `clip-path` + `translateX` по `steps(3)` |
| scroll exit | нет, намеренно |
| hover | строка дорожки: инверсия в плиту (правило «наведение переворачивает материал») |
| idle | нет |
| click | переключатель «через Atlas» кладёт кальку поверх листа: `opacity` 0 → 0,72 за 480 мс `--m-settle`, без blur (М3). На кальке — второй маршрут до ближайшего сервера |
| transition-out | нет |

**Слой изображения.** Нет, только DOM.

**Мобильный.** Дорожки вертикально друг под другом на всю ширину,
датамош — 8 плиток. Калька — тап по переключателю, 44 px.

**Бюджет.** ~16 узлов, композитор (`transform`, `clip-path`); одна
шкала. Сейчас процент считает `@property --lap-n` в `::after` —
остаётся, это показ прогресса, а не счётчик ради эффекта.

**A11y.** `role="img"` с `aria-label` (как сейчас). Переключатель —
`<button aria-pressed>`. Плитки `aria-hidden`.

### Лист 03 · *Граница* (кто мы)

**Цель.** Сказать, кто мы, без «команды профессионалов»: мы те, кто
называет границу.

**Правило.** Первая из двух плит главной: плита `--a-plate`, бумага
набором. **Нарушение.** Одна строка — единственное отрицание —
набрана киноварью на плите (`--a-route-lume`, 8,68:1), потому что это
замер, а не лозунг: число устройств из кода.

**Текст (черновик).**

> Сайты и приложения перестали открываться.
> Ваш интернет тут ни при чём.
>
> Мы называем границу:
> {DEVICE_LIMIT} устройств — а не «безлимит».
> {COUNTRY_COUNT} стран — а не «весь мир».
> Где не знаем точно, пишем *ориентировочно*.

Три такта манифеста остаются; средний («ваш интернет тут ни при
чём») — на плите, как сейчас.

| Состояние | Партитура |
|---|---|
| load | конечный вид без скрипта |
| scroll enter | такты ложатся по порогу: каждая строка `opacity` + `translateY(6px→0)` 480 мс `--m-settle`, стаггер 40 мс (разово, не scrub) |
| scroll progress | нет, намеренно (было: вес по прокрутке на каждом заголовке — снят, A3) |
| scroll exit | нет |
| hover | нет, намеренно: текст, не элемент управления |
| idle | нет |
| click | нет |
| transition-out | нет |

**Слой изображения.** Нет.

**Мобильный.** Такты по одному на экран, кегль по `cqw`.

**Бюджет.** 0 шкал прокрутки, 6–8 разовых анимаций.

**A11y.** Обычные `<p>`; кавычки «ёлочки» в разметке, а не картинками.

### Лист 04 · *Девятнадцать стран* (кейсы как пространство)

**Цель.** Показать присутствие честно: где есть сервер, сколько до
него, и где его нет.

**Правило.** Карта в названной проекции на полную ширину листа,
штриховка суши гравюрным штрихом, изохроны вокруг городов с
серверами. **Нарушение.** Страны без сервера — белые пятна: не
заштрихованы и подписаны «сервера пока нет». Карта сама показывает
свою неполноту.

**Текст (черновик).**

> Лист 04 · *{COUNTRY_COUNT словами}*   ← из числа, не руками
>
> [карта]
>
> Равнопромежуточная проекция: чем дальше от экватора, тем шире
> страны. Время ответа — *ориентировочно*, от {Москва, по умолчанию}.
> Каждая пятая линия подписана.
>
> [таблица-указатель: страна · город · ориентировочно, мс · есть
> сервер]

Проекция — не выдумка: `world-map.ts` — сетка 3° × 3°, то есть
равнопромежуточная (plate carrée). Подпись называет её искажение —
позиция «называем границу» доведена до картографии (A8 §1.3, «редко»).

| Состояние | Партитура |
|---|---|
| load | без скрипта: статичный SVG листа, собранный на сборке из `world-map.ts` + `locations.ts` |

| scroll exit | нет |
