## 0. Сквозные правила

### 0.1 Информационная архитектура: сайт — атлас

Сайт — одно издание из пронумерованных листов. Главная — сквозной
маршрут через листы 01–08; остальные разделы — отдельные листы того же
атласа, с тем же полем и номером.

```
Выпуск: сентябрь 2026                                   масштаб 1 : 1
┌────────────────────────── ГЛАВНАЯ (маршрут) ─────────────────────────┐
│ 00 раскладка → 01 обложка → 02 одна и та же страница → 03 граница    │
│ → 04 девятнадцать стран → 05 легенда → 06 три шага → 07 указатель    │
│ → 08 финал                                                           │
└──────────────────────────────────────────────────────────────────────┘
Отдельные листы:  10 тарифы (/pricing)   11 выделенные серверы (/vds)
                  12 устройства (/devices) 13 для бизнеса  14 поддержка
                  15 контакты  16 безопасность  17 инфраструктура  18 о нас
                  ∅ 404 «белое пятно»
Выходные данные (футер) — на каждом листе.
```

Номер листа — постоянное свойство раздела (одна таблица в
`src/lib/nav.ts`), не порядковый номер на странице.

### 0.3 Палитра «Лоция» — как применяется

Токены и контраст — `CONCEPTS.md`, «Палитра "Лоция"». Язык морской
карты: бумага и вода белые, мели — тона синего, суша — серый рельеф с
отмывкой, изобаты и изохроны — линии.

| Что | Цвет |
|---|---|
| Главное действие | кобальтовая плита `--a-cobalt`, белый текст; наведение — `--a-cobalt-deep` |
| Второе действие | текст `--a-ink`, подчёркивание прочерчивается |
| Маршрут читателя, живое показание | `--a-cobalt` |
| Изохроны времени ответа | полосы мелей: ближе к серверу — `--a-shoal`, дальше — белый; линии `--a-g200` |
| Суша | штрих `--a-g200`, отмывка `--a-g400` (только графика) |
| Плоскости и объём | ступени `--a-paper` → `--a-g50` → `--a-g100` |
| Две плиты главной (лист 03, лист 08) | `--a-cobalt`, белый набор; на плите кнопка белая, текст кобальтовый |
| Наведение на строку (тариф, указатель, город) | строка переворачивается в кобальтовую плиту |
| Ошибки форм | `--g-rock`, только там |

### 0.5 Поле листа (глобальная раскладка)

- **Поле.** Сверху одна волосяная линия `--a-g200` во всю ширину;
  пункты меню MTS Wide стоят на ней. Никакой стеклянной шапки.
- **Углы.** Левый верхний — знак Atlas (`BrandMark.tsx` не меняется).
  Правый верхний — «лист 04 · *Девятнадцать стран*». Левый нижний —
  «выпуск: сентябрь 2026, {время}» (живое, см. выходные данные).
  Правый нижний — масштаб или «ориентировочно».
- **Сетка.** Модуль колонки один: `--gh-col` (4 / 8 / 12). Рваная
  посадка сцен сохраняется.
- **Объём.** Сцены лежат на ступенях серого: лист на бумаге, врезки на
  `--a-g50`, таблицы на `--a-g100`. Теней нет.
- **Мобильный.** Меню уходит в указатель листов на весь экран,
  вызывается номером листа в углу. Тап-зоны от 44 px.

### 0.6 Токены движения

| Токен | Значение | Где |
|---|---|---|
| `--m-pen` | `linear` | прочерчивание линий, край маски перелистывания, поток по линиям |
| `--m-settle` | `cubic-bezier(0.2, 0, 0, 1)` | подписи ложатся, листы раскрываются |
| `--m-turn` | `cubic-bezier(0.65, 0, 0.35, 1)` | смена номера листа, инверсия по наведению |
| `--m-tide` | `cubic-bezier(0.37, 0, 0.63, 1)` | холостой слой: прилив, дыхание, свет |
| `--d-1` | 240 мс | отклик на руку |
| `--d-2` | 480 мс | подпись, калька, второй прогон |
| `--d-3` | 900 мс | перелистывание, потолок любого события |
| `--d-tide` | 6–12 с | цикл холостого слоя блока |
| `--d-sun` | реальное время | свет рельефа по положению солнца |
| `--stagger` | 40 мс | подписи по `sibling-index()` / `--i` |

Пружин и отскоков нет. Событие дольше 900 мс запрещено.

### 0.7 Бюджет движения: живое, но не перегруженное

Решение владельца 10.09: анимации живые, у каждого блока все четыре
состояния — load, scroll, hover, idle. Замер `research/05_MOTION.md`
показал две вещи, и обе учтены: движения **по прокрутке** у Atlas
больше нормы (491 при медиане 330), а в покое страница была мёртвой
(жалоба «сайт мёртвый», `research/SUMMARY.md`). Поэтому жизнь
набирается холостым слоем и рукой, а прокрутка сокращается.

| Режим | Правило | На главной |
|---|---|---|
| **Прокрутка (scrub)** | маршрут читателя (одна шкала на всю главную); дорожки листа 02; прочерчивание изохрон листа 04; разворот легенды 05 на десктопе | **4 шкалы** (сейчас 49); цель метрики 350–400 |
| **Разовое по порогу** (`animation-trigger`, фолбэк — класс по IntersectionObserver) | М1 второй прогон у каждого листа; подписи ложатся | каждое ≤ 900 мс |
| **Холостое** | у каждого блока свой медленный слой **со смыслом** (прилив мелей, свет по солнцу, поток по линии со скоростью тарифа) | один на блок; одновременно в кадре — не больше трёх |
| **Рука** | калька М3, вязкость = время ответа, инверсия строки, прочерчивание подчёркивания | свободно |
| **Переходы** | М2 перелистывание листа | одно на навигацию |

Условия для холостого слоя, без исключений:

1. Только `transform`, `opacity` и CSS-переменные через `@property`;
   ни `background-position`, ни `filter`, ни свойств раскладки.
2. Слой работает только в кадре: `animation-play-state: paused` вне
   его (один общий IntersectionObserver на документ) и в скрытой
   вкладке.
3. На странице один rAF-цикл — холст карты. Всё остальное холостое —
   CSS.
4. `prefers-reduced-motion`: холостой слой выключен, конечный кадр.
5. Флаг `?static=1`: выключено всё холостое, холст рисует один кадр —
   стабильный снимок для скриншотов и design-critic.
6. Каждый холостой слой что-то значит. «Дыхание ради дыхания» не
   принимается.

### 0.8 Слой изображения сайта: один холст

Один Canvas 2D на сайт — «лист карты» (эволюция `SignalField`).
Рисует: штриховку суши по маске `world-map.ts` серым гравюрным
штрихом, отмывку рельефа, полосы мелей-изохрон тонами синего, маршрут
читателя кобальтом.

- **Свет по солнцу.** Направление отмывки рельефа = азимут солнца для
  часового пояса читателя (считается локально из `Date`, без
  геолокации). Утром тень ложится на запад, вечером на восток. Это
  реакция на время суток из категории 10 промта, со смыслом: карта
  освещена так же, как мир за окном читателя. Пересчёт раз в минуту,
  не на кадр.
- **Потолок.** 1400 штрихов в кадре (Walkable Atlas), ≤ 4 мс на кадр на
  среднем телефоне; цикл встаёт вне кадра и в скрытой вкладке.
- **Без скрипта и при reduced-motion** — статичный SVG того же листа,
  собранный на сборке, свет — полдень.
- `SignalTrace` (FPS) с публичных листов уходит (A7 §6, п. 11).

WebGL, WebGPU и 3D-библиотек нет (`STACK_DECISION.md`).

## 1. Главная — маршрут

### Лист 00 · *Раскладка* (intro)

**Цель.** Показать, что сайт — лист атласа, не заставив ждать ни
миллисекунды.

**Правило.** Страница отрисована сервером в конечном виде до любого
скрипта. **Нарушение.** При первом посещении за сессию поверх готовой
страницы проходит развёртка: две линии сгиба расходятся от центра к
краям, как раскрывается сложенная карта. Контент под ними уже на месте
и кликабелен.

**Текст.** В правом нижнем углу на время развёртки — «лист
раскладывается», затем подпись меняется на масштаб.

| Состояние | Партитура |
|---|---|
| load | 0 мс: страница видна. 80 мс: две линии сгиба `--a-g400` 1 px в центре, `scaleX/scaleY` 0 → 1 за 600 мс `--m-pen`. 680 мс: линии гаснут `opacity` 240 мс `--m-settle`. Итого 920 мс, но содержимое доступно с 0 мс |
| scroll | не повторяется |
| hover | слой `pointer-events: none` |
| idle | после развёртки передаёт жизнь листу 01 (прилив мелей стартует в конце развёртки) |
| click | клик в любой момент — конечный кадр |
| transition-out | нет |

**Бюджет.** 0 КБ библиотек, 2 узла, `transform` и `opacity`. Не
влияет на LCP.

**A11y.** `aria-hidden`; при reduced-motion и `?static=1` не
создаётся. Флаг первого посещения — `sessionStorage` в try/catch.

### Лист 01 · *Обложка* (hero-манифест)

**Цель.** За три секунды: это атлас, и интернет здесь работает
одинаково отовсюду.

**Правило.** Две строки выключены по ширине колонки, каждая своим
кеглем (`100cqw / k`). **Нарушение.** В строку подзаголовка между
словами вставлен фрагмент карты высотой в строчную букву: мели-изохроны
вокруг ближайшего сервера. Объект первого экрана рождается из набора
(Paul Kalkbrenner, The Watch — A7).

**Текст (черновик).**

> одинаково
> отовсюду
>
> От *вашего города* [▭ фрагмент карты] до ближайшего сервера.
> VPS-ускоритель Atlas Secure: {COUNTRY_COUNT} стран, без просадок.
>
> [ {TRIAL_DAYS} дня бесплатно ]   Выделенные серверы
>
> *{дата}, {время}. {Город или «Москва, по умолчанию»}. До ближайшего
> сервера, в {CLOSEST.city}, — {мс} мс{, ориентировочно}.*

Заголовок — строчными, Literata 300, краской. Отдельное слово
«отовсюду» можно набрать кобальтом — единственная цветная строка
дисплея на сайте. Подпись внизу — курсивом, в голосе натуралиста.
Выносок «без оговорок» уходит: рвать прямоугольник теперь будет
фрагмент карты.

| Состояние | Партитура |
|---|---|
| load | Заголовок виден сразу (LCP). 200 мс: мели фрагмента карты прочерчиваются от сервера наружу, 5 полос × 120 мс `--m-pen`, стаггер 40 мс. 700 мс: подпись ложится `translateY(4px→0)` + `opacity` 480 мс `--m-settle`. Замер `LivePing` приходит — число мс меняется на месте |
| scroll enter | лист уже в кадре |
| scroll progress | начинается маршрут читателя: пунктир кобальтом выходит из фрагмента карты и уходит по диагонали вниз; длина = прогресс прокрутки главной (одна шкала `scroll(root)`) |
| scroll exit | заголовок уходит вместе с листом, без анимации |
| hover | кнопка: кобальт → глубокий кобальт 240 мс `--m-turn`. Фрагмент карты: мели догоняют курсор с постоянной времени = время ответа читателя (A2 «Вязкость», τ 8–400 мс) |
| idle | **прилив:** полосы мелей медленно расходятся и сходятся, `scale` 1 → 1,02, 8 с `--m-tide`, бесконечно, только в кадре. **Живое показание** мигает. **Свет** рельефа следует за солнцем |
| click | «{TRIAL_DAYS} дня бесплатно» → М2 перелистывание на лист входа |
| transition-out | М2 |

**Слой изображения.** Вырезка единственного холста или SVG, пока холст
не проснулся: ≤ 200 штрихов.

**Мобильный.** Строки остаются выключенными (кегль по `cqw`). Фрагмент
карты переносится на отдельную строку во всю ширину, высотой 3
строчных. Вязкость отвечает на касание. Гироскоп не используем: на iOS
нужен запрос разрешения, и первый экран просил бы доступ к датчику.

**Бюджет.** LCP — текст h1; дисплейный набор Literata урезан и
предзагружен, метрик-переопределение (CLS 0). Холст ≤ 200 штрихов,
≤ 2 мс/кадр. JS листа ≤ 6 КБ gz сверх текущего. Кадр помещается в
экран 900/800/844 по высоте.

**A11y.** h1 — «одинаково отовсюду»; фрагмент карты `aria-hidden`.
Обновление числа — `aria-live="polite"` один раз. Город без согласия
не определяется.

### Лист 02 · *Одна и та же страница* (почему)

**Цель.** Показать разницу, которую человек знает по опыту: страница
висит — страница открылась.

**Правило.** Две дорожки одной длины на модуле колонки. **Нарушение.**
Медленная дорожка распадается на блоки 8×8 и смазывается вбок
ступеньками, как зависший видеозвонок (A4 «Датамош»), и выходит за
правое поле листа.

**Текст (черновик).**

> одна и та же страница
>
> без ускорителя ——————————— 61 % — *не отвечает*
> через Atlas   ——————————————————— готово, *{CLOSEST.city}*
>
> Atlas шифрует соединение и меняет страну выхода — и страница
> открывается оттуда, откуда открывается.
>
> [ как сейчас | через Atlas ]  ← калька

Исправлено: `готово · {город}` (`Home.tsx:188`, мета-строка через
среднюю точку из AI-кластера №5) → «готово, *Минск*».

| Состояние | Партитура |
|---|---|
| load | без скрипта: медленная на 61 % с подписью, быстрая полная |
| scroll enter | М1 второй прогон: контуры дорожек `--a-g200`, через 240 мс заливка быстрой кобальтом со сдвигом приводки 3 px → 0 за 480 мс |
| scroll progress | дорожки растут по шкале секции (существующий `--lap`). На 61 % медленная останавливается и распадается на 12–16 плиток `clip-path` + `translateX` по `steps(3)` |
| scroll exit | плитки медленной дорожки остаются рассыпанными |
| hover | строка дорожки — кобальтовая плита |
| idle | **быстрая дорожка:** по ней раз в 4 с проходит светлый блик `--a-shoal-lume` (`translateX`, 1,2 с `--m-pen`) — поток идёт. **Медленная:** плитки вздрагивают на 1 px по `steps(2)` раз в 2,4 с — всё ещё висит |
| click | переключатель «через Atlas» кладёт кальку: `opacity` 0 → 0,72 за 480 мс, без blur (М3). На кальке — второй маршрут до ближайшего сервера |
| transition-out | нет |

**Мобильный.** Дорожки на всю ширину, датамош — 8 плиток. Калька —
тап, 44 px.

**Бюджет.** ~16 узлов, композитор; одна шкала; два CSS-цикла в покое.

**A11y.** `role="img"` с `aria-label`; переключатель — `<button
aria-pressed>`; плитки и блик `aria-hidden`.

### Лист 03 · *Граница* (кто мы)

**Цель.** Сказать, кто мы, без «команды профессионалов»: мы те, кто
называет границу.

## 5. Первые шаги фазы D (до экранов)

1. Флаг `?static=1` — стабильный кадр для скриншотов и design-critic.
2. Токены `--a-*` на `:root` (урок CLAUDE.md: не внутри `.g`).
3. Шрифты: Literata через `next/font` (урезанный дисплейный набор,
   курсив, проверка `tabular-nums` в браузере), MTS Wide Medium через
   `next/font/local`, перемер `k` для выключки.
4. Общий контроллер холостого слоя: один IntersectionObserver на
   документ, `animation-play-state`, reduced-motion и `?static=1`.
