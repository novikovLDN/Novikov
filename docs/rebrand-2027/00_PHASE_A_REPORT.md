# Фаза A — сводный отчёт

Ребрендинг Atlas Secure по методу `MEGA_PROMPT_agency_redesign_2026-2027.md`.
Дата: 10 сентября 2026. Промт написан под маркетинговое агентство;
владелец подтвердил, что объект — Atlas Secure («VPS-ускоритель» и
выделенные серверы). Везде, где промт говорит «агентство», читается
«Atlas».

Этот файл — оглавление и выжимка. Доказательства, таблицы и ссылки
лежат в разделах.

## Двенадцать выводов фазы A

1. **Отличие Atlas больше не держится на форме.** Скилл frontend-design
   от Anthropic (редакция сентября 2026) описывает «газетную вёрстку с
   волосяными линейками и нулевым радиусом» и «почти чёрный фон с
   кислотно-зелёным акцентом» как два из пяти типовых наборов черт
   сгенерированной страницы. Форма «Редакционного корпуса» совпадает
   с обоими. Отличают Atlas то, чего у генератора нет: выключка по
   ширине, правило «цвет только для измеренного» и настоящие
   показания с устройства читателя. [A1 §7, противоречие 1]

2. **Жюри награждает сцену, ниша — предмет.** WebGL-холст есть у 10
   из 12 студий и у 14 из 22 лауреатов, но у 3 из 17 агентств и 7 из
   16 инфраструктурных продуктов. В инфраструктуре холст всегда
   рисует один предмет: стойку у Oxide, куб у Resend. Два 2D-холста
   Atlas — уровень ниши. [A2 §6.1]

3. **Рекомендация промта «WebGPU как подпись сайта» для Atlas
   переоценена.** Контекст WebGPU создали 2 сайта из 67. Cerebrium
   откатился на WebGL из-за ~20 с компиляции шейдеров. Для русской
   аудитории WebGPU доступен 35–61% посетителей против 84% в мире.
   Основной путь для этой аудитории — WebGL 2. [A2 §6.2, A4 §11]

4. **Движения по прокрутке уже больше нормы, поэтому добавлять можно
   только взамен.** Atlas даёт 491 при медиане 330. Холостой бюджет
   (два приёма) исчерпан и совпадает с нормой (медиана у студий 2, у
   агентств 0). Свободный запас есть только в отклике на руку и в
   разовых событиях. [A3, бюджет движения]

5. **Главный перенос из ниши — показание о читателе, а не о
   странице.** Mullvad первой строкой сообщает посетителю его
   состояние и даёт одно действие. У Atlas механика есть (`LivePing`,
   `SignalTrace`), но показания отвечают на вопрос «как работает
   страница». [A2 §6.5]

6. **Штриховой материал актуален, если штрихи что-то рисуют.** Son
   Daven (Site of the Month, июнь 2026) складывает из штрихов фигуру,
   Ghostty собирает анимацию из символов. `SignalField` той же семьи,
   но абстрактен. [A2 §6.4]

7. **Прелоадеры и ворота «Enter Site» не берём.** У 10 из 67 сайтов
   через 6,5 с на экране нет содержимого. Правило Atlas «без скрипта
   страница отрисована целиком» сильнее практики лауреатов. [A2 §6.6]

8. **Агентства выходят из классики через метафору интерфейса, а не
   через WebGL.** Рабочий стол у Mother, меню-экран у Uncommon,
   переписанный баннер cookie у Heretic. Классикой почти всегда
   остаётся служебное: 404, cookie, ошибки форм. [A2 §6.10]

9. **Запреты в промте не работают, работает спецификация.** «Не
   используй этот цвет» сдвигает модель на другую фиксированную
   палитру. Работают hex-коды, числа и варианты до кода. Это правило
   переносится на CLAUDE.md и промты фазы D. [A6, правила 2 и 5]

10. **Сдержанность снова выигрывает.** Malvah (Studio of the Year
    2025): «уверенности не нужен декор». PlanetScale убрал холст с
    главной. Награда при этом не критерий: MindMarket получил SOTM
    с Inter и «пилюлями». [A2 §6.9]

11. **Стек менять не нужно.** Остаёмся на Next.js 16 + GSAP + Lenis +
    нативные scroll-driven. 3D, если будет, — three r186 без
    React-обёртки, одна сцена после LCP. Нативные scroll-driven
    анимации в Firefox до сих пор за флагом, поэтому каждое правило
    обязано стоять под `@supports`. [A4 §0, §5]

12. **Узкое место для фазы D — стабильный кадр, а не 3D.** Сайт
    никогда не отдаёт стабильный кадр, из-за этого Playwright не
    снимает скриншоты, и не работают design-critic, визуальные
    регрессии и итерация шейдеров. Первый шаг фазы D — флаг
    `?static=1`. [A5 §11]

## Где исследования разошлись с CLAUDE.md

Решения по этим пунктам — фаза B или владелец. Сам ничего не менял.

| Правило CLAUDE.md | Что показал замер | Предложение |
|---|---|---|
| «Каждый блок анимирован: load / scroll / hover / idle. Без исключений» | против: замер движения, «холостого ровно два» в том же файле, frontend-design | «У каждого блока **определено** поведение в четырёх состояниях; "не движется, намеренно" — допустимое значение» |
| Запрещены «счётчики цифр», при этом `@property` для бегущих чисел и `RollingNumber` | формально counters | Запрещён отсчёт ради эффекта (0 → 19 стран); разрешён показ меняющегося измеренного значения |
| «3D: WebGPU + fallback» против «второй холст заводить нельзя» | 3D-сцена — это второй холст | Выбрать: 3D заменяет `SignalField` или 3D нет. Решается выбором направления |
| «Фон `#FFFFFF`, не кремовый» | чисто белых 9 из 24 светлых корпусов; у инфраструктуры 0 из 6 | Позиция, а не замер. Решается выбором направления |
| «Моноширинной в системе нет» | моно у 8 из 16 инфраструктурных сайтов — это «показание прибора» | Моно или табличные цифры только для измеренного |
| «Выключку по ширине не делает ни один» | делают Pantheon, Son Daven, Uncommon AU, ChillBase, Huge, Noomo | Приём держать, называть уникальным перестать |
| «У ВСЕХ двадцати в первом экране есть объект» | неверно для инфраструктуры: PlanetScale, Collins, Mischief | Уточнить формулировку |
| Лайм только для измеренного | в выборке лайм почти всегда цвет кнопки | Не ошибка, а риск: проверить на людях |
| «Motion: всё нативное, ноль библиотек» | в проекте GSAP и Lenis | Исправить формулировку |
| Tech Stack: Nodemailer, хранилище в памяти, Xray | в коде Resend, PostgreSQL, Remnawave | Переписать раздел |
| CLAUDE.md на 284 строки прозы о дизайне | модель частично игнорирует раздутый CLAUDE.md | Раздел дизайна вынести в скилл, в CLAUDE.md оставить 10–15 жёстких правил |

## Ошибки в наших же прежних документах

- `docs/01_RESEARCH.md` находка 1: scroll-driven анимации не
  кроссбраузерные, в Firefox они за флагом.
- `docs/01_RESEARCH.md` находка 4: Interop 2026 не довёл WebGPU до
  всех браузеров.
- `docs/01_RESEARCH.md` находки 16–19 (тёплый off-white, тени,
  mesh-градиенты, стеклянная шапка) отменены и CLAUDE.md, и A1.
- `research/03_AGENCY_TEARDOWN.md`: «выключку по ширине не делает
  никто» — устарело.
- `docs/ADR/0003` и `docs/QUESTIONS.md` №15: вопрос о лицензии GSAP
  закрыт. С 30.04.2025 GSAP со всеми плагинами бесплатен для
  коммерческого использования.
- `docs/03_DESIGN_SYSTEM.md` §7: бюджет шрифтов ≤100 КБ не
  выполняется, по замеру около 128 КБ.

## Технический долг, найденный попутно

- `brand/Cursor.tsx` подключён в корневом `layout.tsx` и работает на
  страницах старого корпуса, хотя кастомный курсор запрещён.
- `@view-transition { navigation: auto }` в `brand.css:1448` не
  работает: навигация через `<Link>` в App Router его не вызывает.
- `Home.tsx:188` — `готово · {город}`: мета-строка через среднюю точку
  из пятого AI-кластера.
- Blender MCP «connected» только формально: аддона в Blender 5.2 нет.
  Нужно выбрать один из двух мостов, оба занимают порт 9876.
- У агента `frontend-builder` нет инструмента `Agent`, поэтому его
  инструкция вызывать design-critic не выполнится.
- Cloudflare: с июня 2025 российские сети фильтруют часть IP и режут
  соединения с ECH. ADR-0012 этого не учитывает.
- `package.json`: `autoprefixer` и `nodemailer` не используются;
  `@types/*` лежат в dependencies.
- Хуков в `.claude/settings.json` нет. Предложения H1–H8 — в
  `PIPELINE.md` §8, ничего не установлено.
- Репозиторий лежит на Рабочем столе, который синхронизирует iCloud
  (`docs/ASSUMPTIONS.md`).
