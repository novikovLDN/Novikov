# Фаза B — три направления

Ребрендинг Atlas Secure. Дата: 10 сентября 2026. Основание — фаза A
(`00_PHASE_A_REPORT.md`).

Три направления радикально разные по корпусу, шрифтам, композиции и
технологии. Общее у них только то, что продукт не позволяет менять:

- числа на страницах берутся из кода (`plans.ts`, `locations.ts`,
  `remnawave.ts`), непроверяемое — в `COMPLIANCE-CHECK.md`;
- на витрине «VPS-ускоритель», без «VPN», протоколов и инженерных
  терминов; весь текст на русском;
- никаких прелоадеров, стоковых картинок и эмодзи; иконки только из
  собственного набора;
- страница отрисована без скрипта; `prefers-reduced-motion` упрощает
  слой, а не ломает его;
- бюджет: LCP < 2,5 с, INP < 200 мс, CLS < 0,1, 60 fps на среднем
  телефоне 2024 года.

Контраст всех пар посчитан по WCAG 2.2 на этих hex-кодах. Шрифты
проверены через Google Fonts CSS API на 10.09.2026: у всех
перечисленных бесплатных гарнитур есть кириллица и заявленные оси.

## Направление 1. «Прибор»

**Манифест.** Мы не рассказываем о скорости — мы её меряем, прямо у
вас в браузере. Всё, что на этой странице окрашено, снято с вашего
устройства или с нашего узла, всё остальное — чёрным по белому. Сайт
работает как прибор: одна шкала, одна стрелка, никаких украшений.

Это эволюция нынешнего «Редакционного корпуса»: форма остаётся,
меняется то, что показывают показания.

### Визуальный язык

| | |
|---|---|
| Шрифты | Sofia Sans (текст, вариативная 1–1000), Sofia Sans Condensed (дисплей, прописные). Новое: табличные цифры или Martian Mono (wdth 75–112,5, wght 100–800) **только для измеренных значений** |
| Бумага | `#FFFFFF`; утопленная полоса `#F2F2F0` |
| Краска | `#000000` 21:1 · `#3D3D3D` 10,86:1 · `#6E6E6E` 5,10:1 |
| Измеренное | на бумаге ультрамарин `#0F1BD6` 9,78:1; на плите лайм `#CBF52A` 16,63:1 |
| Материал | бумага, краска, инверсия; поле штрихов первого экрана |

### Motion-язык

- **Темп:** механический, ступенчатый. Показания обновляются рывком, а не плавно.
- **Easing:** `steps(4, end)` для показаний; `cubic-bezier(0.2, 0, 0, 1)` для раскрытий; пружина через `linear()` как токен.
- **Длительности:** 160 / 320 / 640 мс.
- **Звук:** нет.
- **Что меняется относительно нынешнего:** −5 анимаций по прокрутке (№14, №8, №12, `gh-weight` на каждом `.gh-h2`, №5), +3 взамен. Метрика прокрутки должна упасть с 491 примерно до 400 (оценка, нужен повторный замер).
- **Новые приёмы:** A1 «Рукопожатие вместо прелоадера», A2 «Вязкость = задержка», A3 «Шифр-шов», A5 «Страница меряет саму себя» (`ANIMATION_CATALOG.md`).

### 3D-язык

3D нет. Остаётся один Canvas2D-холст поля и один прибор `SignalTrace`.
Подписью сайта становится не технология, а **показание о читателе**:
первая строка как у Mullvad, только про скорость — «ваша задержка до
ближайшего узла сейчас — N мс».

## Направление 2. «Атлас»

**Манифест.** Атлас — это свод карт, а не щит. Мы прошли территорию,
измерили её и нанесли на лист, включая белые пятна. Сайт — лист
атласа, на котором путь от вашего города до ближайшего узла
прочерчен измерением, а не обещанием.

Направление выводит бренд из его имени и из архетипа, записанного ещё
в `docs/02_BRAND.md` («Хранитель с оптикой Картографа»), но до сих
пор не показанного визуально.

### Визуальный язык

| | |
|---|---|
| Дисплей | **Literata** — вариативная антиква с оптическим размером (opsz 7–72, wght 200–900, курсив). Строчными, не прописными: антиква на оптическом размере 72 — это надпись на карте, а не газетный заголовок |
| Текст и интерфейс | Sofia Sans (оставляем: проверена на кабинете и формах) |
| Показания и координаты | **Martian Mono** (wdth 75–112,5, wght 100–800) — только измеренное и координаты листа |
| Платная альтернатива | лицензионный гротеск с кириллицей вместо Sofia Sans; в прошлом исследовании кириллица отмечена у Söhne, Suisse Int'l, Aeonik, Neue Montreal [проверить у фаундри] |
| Бумага | **`#ECEEE9`** — холодная серо-зелёная, как топографический лист. Не тёплая кремовая: тёплый off-white — AI-кластер №1 (A1). Утопленная полоса `#E0E3DC` |
| Краска | `#15171A` 15,37:1 · `#474B51` 7,51:1 · `#5E6368` 5,19:1 (на полосе 4,68:1) |
| Измеренное на бумаге | **ваш маршрут и ваша задержка** — киноварь `#B8321A` 5,12:1; **сеть и узлы** — синь `#1D3FA8` 7,72:1. Два цвета — два субъекта: вы и сеть. Всё остальное — краской |
| Измеренное на плите | плита `#15171A`, бумага на ней 15,37:1, показание — светлая киноварь `#FF9B6A` 8,68:1 |
| Материал | лист атласа: рамка с делениями координат по краю, номер листа, изолинии |
| Геометрия | радиус 0; поля листа с делениями вместо волосяных линеек между блоками; сетка — картографическая проекция на модуле `--gh-col` |
| Правило | всё стоит на координатной сетке листа и подписано номером листа |
| Нарушение | **маршрут читателя** — одна измеренная линия киноварью — проходит по диагонали через все листы, от первого экрана до финала, игнорируя сетку. Прокрутка её прочерчивает |

### Информационная архитектура

Сайт — атлас, а не стопка секций. Разделы — пронумерованные листы
(«Лист 03 — Тарифы»). Навигация — указатель листов с мини-картой.
Прокрутка главной — движение по маршруту от города читателя к
ближайшему узлу. 404 — «белое пятно: этот лист ещё не нанесён».
Служебные места (cookie, ошибки форм) говорят языком карты — это
вывод A2 §6.10, где агентства остаются классическими.

### Motion-язык

- **Темп:** плоттер — медленный и точный. Линии чертятся с постоянной скоростью, как пером.
- **Easing:** `linear` для прочерчивания; `cubic-bezier(0.2, 0, 0, 1)` для подписей, которые «ложатся» на лист; ступеней нет.
- **Длительности:** 240 / 480 / 900 мс; стаггер подписей 40 мс.
- **Характер:** чертёжный, без пружин и отскоков.
- **Звук:** нет.
- **Бюджет:** маршрут заменяет три существующие анимации прокрутки (№14, №12, №8), а не добавляется к ним. Холостого движения по-прежнему два: мигание живых показаний и медленный дрейф изолиний вместо ленты фактов.

### 3D-язык

Полной 3D-сцены нет. Поле штрихов первого экрана (`SignalField`)
перерисовывается в **изолинии задержки** — линии равного времени до
узла, как изохроны на карте транспорта. Каждая следующая линия —
плюс 10 мс от узла. Это авторский приём: в 53 разобранных сайтах его
нет (проверка ограничена выборкой).

- **Технология:** Canvas2D, как сейчас; если не хватит плотности — один WebGL 2 quad с фрагментным шейдером (3–5 КБ своего кода, A4 «если бюджет меньше»). Холст по-прежнему один.
- **Данные:** ориентировочные задержки из `locations.ts`, помеченные как оценка; живое значение читателя — из `LivePing`.
- **Свет:** нет. Глубину даёт плотность штриха, как на гравюре.
- **WebGPU:** не нужен и не подпись. Честно: выгода невидима, а 35–61% охвата в РФ означает, что подписью он не станет.

### Ещё два авторских приёма

- **Лист, который сдвигается под читателя.** Проекция карты центрируется на городе читателя, если он определён, иначе на Москве, помеченной как «по умолчанию». Нужна юридическая проверка показа города (A2).
- **Белое пятно.** Страны без узла на карте присутствия не прячутся, а честно показаны незаштрихованными с подписью «узла пока нет». Это позиция бренда «называем границу» (`02_BRAND.md`).

нет. Переделка корпуса на всех публичных страницах, 5–7 недель.

## Направление 3. «Трасса»

**Манифест.** Скорость — это ощущение в теле, а не число в тарифе.
Сайт проходится как круг: разгон, прямая, торможение перед
поворотом, финиш. Мы показываем разницу между быстрым и медленным
каналом так, чтобы её почувствовала рука.

### Визуальный язык

| | |
|---|---|
| Дисплей | **Tektur** — вариативная (wdth 75–100, wght 400–900), техно-гротеск с кириллицей; крайние кегли, сжатие по оси ширины на скорости |
| Текст | **Geologica** (wght 100–900) |
| Телеметрия | **Martian Mono**, узкая ширина |
| Бумага | `#FFFFFF`, но плита `#0A0A0A` занимает около половины полосы |
| Краска | `#0A0A0A` 19,80:1 · `#707070` 4,95:1 |
| Измеренное | на плите — лайм `#D7FF1F` 17,17:1 (на бумаге 1,15:1, поэтому только на плите); медленный канал на бумаге — тормозной красный `#E0240E` 4,74:1, на плите `#FF4A2E` 5,91:1 |
| Материал | телеметрия гонки: графики скорости, полосы смаза, длинные горизонтальные плиты |
| Геометрия | срезы под 8° через `clip-path`; горизонтальные линии скорости |
| Правило | всё движется и выстроено по горизонтали |
| Нарушение | одна вертикальная линия финиша в конце главной, неподвижная |

### Motion-язык

- **Темп:** быстрый, агрессивный.
- **Easing:** `cubic-bezier(0.87, 0, 0.13, 1)` (expo in-out) для переходов; скорость прокрутки управляет наклоном и смазом (GSAP velocity).
- **Длительности:** 160 / 320 / 600 мс.
- **Характер:** резкий, с перегрузкой в разгоне.
- **Звук:** опционально, выключен по умолчанию — короткий тик пакета по нажатию.
- **Приёмы:** A4 «Датамош медленной дорожки», горизонтальная сцена во весь экран, наклон от скорости прокрутки.

### 3D-язык

Одна сцена three r186 без React-обёртки (A4): **канал как тоннель
световых линий**, камера летит вдоль него по прокрутке; пакеты —
частицы. `WebGPURenderer` + TSL, откат на WebGL 2 — встроенный.

- **Бюджет:** 20–50 тыс. частиц на WebGPU (compute), 5–10 тыс. на WebGL 2; +190–300 КБ gz на 3D-чанк, загрузка после LCP и только на сильных устройствах (`@pmndrs/detect-gpu`); AVIF-постер для остальных и для reduced-motion.
- **Подпись:** compute-частицы на WebGPU. Честно: их увидят 35–61% посетителей из РФ.
- **Свет:** эмиссионные линии, лёгкий bloom через встроенные TSL-узлы.

## Рекомендация: направление 2 «Атлас»

1. **Это единственное направление, где бренд выводится из самого
   себя.** Имя — «Атлас», архетип — «Картограф», позиция — «измерено,
   а не заявлено». Всё это было записано ещё в `02_BRAND.md`, но
   корпус этого не показывал. Карта изолиний задержки — визуальная
   форма той же позиции.
2. **Оно уводит от AI-кластеров не запретом, а спецификацией.** Фаза A
   показала, что нынешняя форма совпадает с двумя кластерами.
   Строчная антиква на оптическом размере, холодная серо-зелёная
   бумага, изолинии и маршрут читателя не совпадают ни с одним.
3. **Оно не противоречит продукту.** Сайт ускорителя не должен быть
   тяжёлым. «Атлас» не добавляет 3D-чанк и не поднимает метрику
   прокрутки, а уменьшает её.
4. **Оно берёт лучшее из двух других.** Из «Прибора» — все показания
   о читателе (A1, A2, A3, A5). Из «Трассы» — только датамош
   медленной дорожки (A4), он дешёвый и без холста.

Чем за это платим: «Трасса» почти наверняка ближе к Awwwards SOTD.
Если приоритет — награда, а не ниша, выбирать надо её, но с
переписанными правилами и жёстким perf-guard.

## Что нужно от владельца, чтобы начать фазу C

1. **Утвердить направление:** 1, 2, 3 или сочетание.
2. **Бюджет на шрифт.** Для «Атласа» всё работает на бесплатных
   гарнитурах; лицензионный гротеск поднимет уровень, но нужен ответ
   (`QUESTIONS.md` №16, до сих пор открыт).
3. **Холст.** Для 1 и 2 правило «один холст» остаётся. Для 3 его
   нужно отменить.
4. **Показ города читателя** — да или нет; от этого зависит первая
   строка и центрирование карты.

После утверждения фаза C: поэкранная партитура (`SCREEN_SCORE.md`)
по всем обязательным блокам промта. Кода до этого нет — так требует
промт.
