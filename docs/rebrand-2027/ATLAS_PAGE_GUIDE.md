# Перевод страницы на корпус «Атлас-издание»

Рабочая инструкция для перевода витринных страниц. Образец — главная:
`src/components/atlas/AtlasHome.tsx` + `src/app/atlas.css`. Решения
владельца — `docs/rebrand-2027/CONCEPTS.md` (разделы «Утверждено» и
«Поправки владельца»), состав главной — `SCREEN_SCORE.md`, редакции 3–4.

## Что уже решено владельцем (не обсуждается)

- Палитра «Лоция»: белый, кобальт `--a-cobalt` #1432B8, серый. Токены
  `--a-*` объявлены на `:root` в `atlas.css`.
- Шрифт — только MTS Wide (Bold 700 для крупного, Medium 500 для
  всего остального). Курсива нет; выделение — цветом и начертанием.
- Тексты простые, о пользе, без жаргона: ни «лист», ни «легенда», ни
  «указатель», ни «проекция», ни «материал». Номера разделов — только
  как графика (`.a-no`, «02»). Владелец дважды вернул тексты со словом
  «тупизм»: каждое предложение должно быть понятно покупателю с
  первого прочтения.
- На витрине «VPS-ускоритель», слова «VPN», протоколов и инженерных
  терминов нет. Выделенные серверы — «выделенные серверы», «VDS», не
  «VPS».
- Анимации «живые»: у каждого блока есть вход (появление), ответ на
  прокрутку или руку и холостой слой. Плюс «больше анимированного
  погружения» — у крупных блоков своя сцена.

## Как собрать страницу

1. **Серверная обёртка с метаданными остаётся** (`page.tsx` с
   `export const metadata`). Тело — компонент страницы.
2. **Оболочка:** `import AtlasShell from "@/components/atlas/AtlasShell"`,
   `<AtlasShell sheetNo="10" sheetTitle="Тарифы">…</AtlasShell>`.
   Номер и название раздела — из `SITE_SHEETS` в `src/lib/nav.ts`.
   Оболочка сама даёт шапку, футер, шрифт, наблюдатель движения,
   `?static=1`. Старые `SiteHeader`/`SiteFooter`/`Header`/`Footer` с
   переводимой страницы убрать.
3. **Разметка:** `<main id="main" className="a-main">`, каждый блок —
   `<section className="a-sheet" data-sheet="10" data-title="…">`, внутри
   `<div className="a-field">`. Заголовок блока —
   `<h2 className="a-h2"><span className="a-no">02</span>текст</h2>`.
4. **Общие классы** (из `atlas.css`, не переопределять):
   `a-h2`, `a-no`, `a-p`, `a-lead`, `a-fine`, `a-actions`,
   `a-btn a-btn-primary` (главное действие — одно на экран),
   `a-btn a-btn-quiet` (второе действие — текст с подчёркиванием),
   `a-plate` (кобальтовая плита; на ней `a-btn-invert` и `a-btn-line`),
   `a-num` (табличные цифры), `a-wide`.
5. **Классы движения** (работают через `MotionController`):
   `a-settle` (подпись ложится при первом входе; `--i` — порядок),
   `a-slide` (въезд сбоку; `--dir: -1|1`, `--i`), `a-print` (второй
   прогон краски), `a-idle` (холостой слой — на паузе вне кадра).
   Кобальтовая плита сама раскрывается шторкой.
6. **Свой CSS — отдельным файлом рядом со страницей**
   (`src/app/<раздел>/<раздел>-atlas.css`, классы с префиксом раздела:
   `ap-` для pricing, `av-` для vds и т.д.), импорт из компонента.
   Внутри файла тот же порядок: раскладка сверху, **всё движение — в
   одном разделе «Движение» внизу файла**, под теми же правилами:
   - только `transform`, `opacity`, CSS-переменные; scroll-driven —
     внутри `@supports (animation-timeline: view())`, базовое
     состояние = конечный кадр;
   - состояния, которые прячут содержимое до входа, — только под
     `.a-js`;
   - холостое — класс `a-idle`;
   - `@media (prefers-reduced-motion: reduce)` — конечный кадр;
   - `html[data-static]` — всё выключено.
7. **Токены**, не хекс: `var(--a-ink)`, `--a-ink-2/-3`, `--a-cobalt`,
   `--a-cobalt-deep`, `--a-shoal`, `--a-g50/100/200/300/400`, `--a-paper`;
   движение: `--m-pen`, `--m-settle`, `--m-turn`, `--m-tide`, `--d-1/2/3`.
   Радиус 0, теней нет, градиентов-фонов нет.

## Что нельзя

- **Ломать логику.** Формы, запросы к API, вход, оплата, выбор тарифа
  и срока, конфигураторы — сохранить поведение один в один. Меняется
  оформление и текст, не функциональность. Если у старой страницы
  клиентский компонент со стейтом — переносить стейт, а не
  переписывать логику.
- **Выдумывать числа и факты.** Цены, скорости, страны, устройства,
  триал — только из `src/lib/plans.ts`, `locations.ts`, `servers.ts`,
  `brand-facts.ts`. Непроверяемое (имена, сертификаты, SLA) — не
  писать или оставить как было на странице и пометить в отчёте.
- **Трогать общие файлы:** `atlas.css`, `src/components/atlas/*`,
  `src/lib/nav.ts`, `layout.tsx`, `globals.css`, `brand.css`,
  `graticule.css`. Если общий файл надо поменять — написать об этом в
  отчёте, не менять самому.
- Эмодзи, сторонние иконки, стоковые картинки, Inter/Roboto/Arial,
  радиус 16px, фиолетовые градиенты, три одинаковые карточки,
  слайдер отзывов, счётчики цифр «0 → N».
- Коммитить. Коммит делает координатор.

## Проверка перед сдачей

- `npx tsc --noEmit -p .` — единственная допустимая ошибка:
  `.next/types/routes.d 2.ts … Duplicate identifier` (конфликтная копия
  iCloud в кэше сборки, к коду отношения не имеет).
- Числа на странице сверены с `src/lib/*`.
- В отчёте: какие файлы изменены, какие блоки и какие анимации у
  каждого, что сохранено из логики, что требует решения владельца.
