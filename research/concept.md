# Дизайн-концепция Atlas Secure

**Действующее направление.** Заменяет прежнюю тёмную концепцию
(фон на всю страницу, лаймовый акцент) полностью. Исследования
[01](01.md), [02](02.md), [03](03.md), [06](06.md) остаются в силе как
база: типографика, ритм, дисциплина воздуха, редакционные приёмы и
конверсионные паттерны оттуда применяются внутри новой визуальной
системы. Материальный слой [04](04.md) — лестница поверхностей на
альфа-белом, кромка света, направленное свечение акцента — остаётся в
силе, но теперь применяется только внутри тёмных фокальных вставок.

**Разбор ориентиров** — [07](07.md). VK Cloud, Yandex Cloud и Selectel
сходятся в одном, несмотря на разных владельцев и агентства: светлый
корпус, реальный интерфейс продукта в первом экране (не абстрактная
графика), цена видна рано, рядом с героем — плотные цифры доверия
(латентность, число локаций, SLA). Сплошной тёмный фон на
технологичном B2C-сайте читается как приём агентского портфолио, а не
язык инфраструктурного сервиса, которому эти три сайта учат смотреть
на себя серьёзно — отсюда пересборка.

**Формула:** светлый технологичный корпус с одним тёплым акцентом.
Фон `#F6F5F2`, поверхности — чистый белый с тонкой кромкой света;
крупная уверенная типографика, много воздуха, единственный яркий
цвет — коралловый оранжевый. Тёмный фон никуда не делся — он стянут в
две **фокальные вставки** (`.px-focal`): герой и финальный блок перед
футером. Там же живёт фирменный мотив — скруглённые кубики на едва
заметной пиксельной сетке. Дорого, тихо, технологично.

---

## 1. Токены — единственный источник значений

Все цвета, радиусы, длительности и кривые объявлены один раз в
`src/app/globals.css` (блок `PIXEL`). Ни один компонент не пишет
«свой» цвет или отступ мимо токена.

| Роль | Токен | Значение |
|---|---|---|
| фон страницы | `--px-bg` | `#F6F5F2` |
| карточки, панели | `--px-surface` | `#FFFFFF` |
| вторичные поверхности | `--px-surface-2` | `#EFEEEA` |
| фокальная вставка (герой, аутро) | `--px-focal` / `--px-focal-2` | `#14140F` / `#1E1E17` |
| акцент | `--px-accent` | `#FF6B45` — коралловый оранжевый |
| акцент, hover | `--px-accent-hi` | `#FF7F5C` |
| тёмный кубик | `--px-brick` / `--px-brick-2` | `#FFB199` / `#14140F` |
| статус «подключено» | `--px-good` | `#0EA394` — бирюзовый |
| заголовки, body | `--px-text` / `--px-text-2` | `#14140F` / `#4B4A44` |
| подписи, мета | `--px-text-3` / `--px-text-4` | тёмный 58% / 42% |
| линии | `--px-line` / `--px-line-2` | тёмный 9% / 16% |
| шаг сетки и кубика | `--px-cell` | `clamp(28px, 3.4vw, 48px)` |

**Правило акцента:** в кадре ровно одно яркое коралловое пятно —
главное действие. Никаких синих, фиолетовых, радуг — в том числе
потому, что синий/бирюзовый уже занят всеми тремя ориентирами
([07](07.md)); коралл — единственный способ не слиться с VK Cloud,
Yandex Cloud и Selectel визуально.

**Правило статуса:** `--px-good` — только состояние системы
(подключено, активно, успех). Декоративно не применяется. На публичных
страницах допустим единственный случай — индикатор «сеть работает».
Статус бирюзовый, а не зелёный: рядом с коралловым акцентом обычный
зелёный всё ещё может прочитаться как второй акцент, а бирюзовый
однозначно читается как «состояние», не «действие».

**Акцент замкнут в токены.** Ни один компонент не пишет цвет мимо
`--px-accent*`. Проверка: подмена одного блока переменных полностью
меняет облик сайта — если бы где-то остался зашитый хекс, он бы
«вылез». Сравнение четырёх акцентов на живом герое — `research/05.md`.

## 2. Фон и фокальные вставки

Базовый корпус светлый, `#F6F5F2`, без текстуры — она была нужна как
приём тёмной страницы и на светлом фоне только шумит. Пиксельная сетка
осталась ровно в двух местах: `.px-focal` (герой, финальный блок перед
футером) и мобильное полноэкранное меню — самодостаточный слой на
`::before` с радиальной маской, а не сквозной div через всю страницу.
Внутри фокальной вставки действуют токены `--px-focal*`, свой белый
текст и свой материальный слой из [04](04.md); любая светлая карточка,
вложенная в фокальную вставку (например, превью интерфейса в герое),
обязана объявлять собственный `color` — иначе она наследует белый текст
фокального фона и становится нечитаемой на собственной белой
поверхности.

## 3. Типографика

Шрифт проекта не меняется: MTS Wide, лицензированы Medium 500 и
Bold 700. Третьего веса в лицензии нет, поэтому Semi Bold из
референса берётся начертанием Bold — подделывать вес синтетически
нельзя.

- `--px-h1`: `clamp(36px, 6vw, 78px)`, `line-height: 1.05`, трекинг `-0.035em`
- `--px-h2`: `clamp(30px, 4.6vw, 60px)`
- лид: 16–18px Medium, цвет `--px-text-2`
- body: 14–15px, мера **не шире 62ch**
- надзаголовки: 11–12px, uppercase, трекинг `+0.16em`
- все числа — `tabular-nums`

## 3.5. Материал поверхностей

Приём материала зависит от фона — это не одна техника, а две, и
смешивать их нельзя.

**На тёмном (`.px-focal`)** — тень невидима на тёмном фоне, поэтому
объём строится светом: лестница поверхностей на альфа-белом
(`--px-lift-1/2/3` как цвета остановок градиента), кромка света по
верхней грани, направленное свечение акцента `--px-glow`. Правила из
[04](04.md) действуют без изменений, но только внутри фокальных
вставок.

**На светлом (весь остальной корпус)** — обычная фотографическая
элевация: `--px-lift-1/2/3` здесь уже не цвета градиента, а готовые
значения `box-shadow` (по токену `--px-edge` / `--px-edge-strong`),
плюс лёгкий альфа-градиент по вертикали для не-плоской заливки. Токен
переопределять по смыслу нельзя без ревизии всех потребителей — при
светлом пивоте именно это и было пропущено один раз (8 мест писали
`--px-lift-*` как цвет градиента и молча переставали рисовать фон).

## 4. Формы

- **Кубик:** скруглённый квадрат, радиус 22% стороны, размер 0.78 ячейки.
- **Кнопки:** мягкий радиус 10px — один вариант на все действия.
- **Навигационные чипы:** пилюля. Это другой класс элементов (переход
  по разделу, не действие), и форма различает их намеренно.
- **Карточки:** радиус 14px, `--px-surface` + альфа-градиент, граница
  `--px-line`, кромка света `--px-edge`. Плоская заливка запрещена.
  Карточка сама объявляет `color: var(--px-text)` — не полагается на
  унаследованный от контекста цвет.
- Скругление кубика повторяется у узлов шагов, монограмм локаций и
  знака раскрытия в аккордеоне — один формальный язык.

## 5. Кнопки

- **Primary:** заливка `--px-accent`, текст `--px-accent-ink` (тёмный).
  Hover: чуть ярче + мягкое коралловое свечение, 160–240ms.
- **Secondary:** `--px-surface-2`, текст `--px-text`, тонкая граница;
  hover — граница темнее / оранжевеет на явных CTA-парах.
- **Композиция блока действий на светлых страницах:** широкая
  акцентная кнопка сверху, две второстепенные под ней в ряд.

## 6. Фирменный мотив — живые кубики

Реализация: `src/components/pixel/CubeCluster.tsx` + блок кубиков в
`globals.css`. Компонент пишет только `--c`/`--r` и класс тона; всё
рисование — в CSS. Кластер и `MiniCubes` живут внутри фокальных
вставок и как буллет надзаголовков — не как элемент на светлом фоне.

- Фигура задаётся строковой картой — силуэт правится глазом в коде.
- Каждые 1.5–3 с один-три кубика перескакивают в соседнюю ячейку,
  640ms, `cubic-bezier(0.4, 0, 0.2, 1)`, стаггер 90ms.
- Кубик не уходит дальше одной ячейки от дома — силуэт остаётся
  узнаваемым, кластер не расползается.
- Занятые ячейки отслеживаются: кубики не наезжают друг на друга.
- При перескоке иногда меняется оттенок (коралловый ↔ приглушённый), 600ms.
- Два-три кубика дышат в собственном медленном ритме (3.6–5.2 с).
- Начальная раскладка и тона детерминированы: случайность на первом
  рендере разошлась бы между сервером и клиентом.
- Позиция и пульсация разнесены по двум элементам, иначе оба эффекта
  дрались бы за `transform`.
- Мотив в малых дозах по всему сайту: `MiniCubes` как буллет
  надзаголовков, узлы шагов, монограммы, знак аккордеона.

## 7. Motion

| Назначение | Длительность | Кривая |
|---|---|---|
| цвет, граница | 160ms | `--px-ease-out` |
| состояния, мелкие сдвиги | 240ms | `--px-ease-out` |
| появление элемента | 420ms | `--px-ease-out` |
| появление секции | 520ms | `--px-ease-out` |
| перескок кубика | 640ms | `--px-ease` |

- Появление секций: `fade + translateY(26px)`, стаггер 100ms,
  **один раз** — IntersectionObserver, а не scroll-timeline (таймлайн
  отматывает анимацию назад при обратной прокрутке) и не
  scroll-jacking (sticky-сцена с искусственно растянутой высотой давала
  мёртвую зону прокрутки — заменена на click/focus-степпер постоянной
  высоты).
- Базовое состояние `.px-reveal` — видимое. Прятать контент разрешено
  только после того, как скрипт подтвердил, что умеет его показать
  (класс `px-js`). Отказ скрипта не может оставить страницу пустой.
- Анимируются только `transform` и `opacity`. Ноль layout shift.
- Ноль JS-библиотек анимации.
- `prefers-reduced-motion: reduce` упрощает слой: контент показывается
  сразу, кубики статичны, числа выводятся конечным значением.

## 8. Логотип

Не меняется. Формы взяты один в один из канонического источника
(`src/app/icon.tsx`) в `src/components/pixel/BrandMark.tsx`;
единственное отличие — заливка `currentColor` вместо жёсткого белого,
чтобы знак работал на любой поверхности.

## 9. Два языка продукта

- **Публичная часть** — это **ускоритель интернета**: скорость,
  стабильность, отсутствие просадок. Слово «VPN» и названия туннельных
  протоколов не употребляются: для посетителя это шум из чужой
  предметной области.
- **Личный кабинет** — говорим прямо: это VPN. Здесь уместны
  подключение, серверы, протоколы, ключи. Пользователь уже внутри, и
  точность важнее позиционирования.

## 10. Честность

- Никаких стоковых иконок, иллюстраций, эмодзи. Только собственный
  набор inline-SVG (`src/components/pixel/Icon.tsx`), единая сетка 24px.
- Никаких выдуманных цифр, логотипов «клиентов», фальшивых отзывов.
  Числа берутся из кода; спорные помечаются в комментарии как
  требующие подтверждения, а не переписываются «покрасивее».
- Для каждого числа на странице можно назвать файл, откуда оно взято.

## Критерии приёмки блока

1. Все значения — из токенов; ни одного «своего» цвета или радиуса.
2. В кадре одно коралловое пятно; зелёный/бирюзовый — только статус.
3. Мера текста не шире 62ch; отступы кратны шагу ритма.
4. Каждая анимация отвечает «что произошло?» или «где я?».
5. Каждая поверхность сама объявляет свой `color` — не полагается на
   унаследованный от родителя (герой на `.px-focal` — источник
   регрессии, если это забыть).
6. 320–1920: без бокового скролла, без тап-зон меньше 44px, без
   непоявившегося контента, без ошибок консоли.
