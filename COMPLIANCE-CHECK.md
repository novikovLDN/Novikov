# COMPLIANCE-CHECK

Список утверждений на публичных страницах, которые **нельзя проверить по
коду**. Каждое нужно либо подтвердить документом, либо снять со страницы.
Публикация неподтверждённой сертификации — юридический и репутационный
риск, а не «маркетинговая вольность».

Дата ревизии: 2026-09-06. Проверял: редизайн витрины под позиционирование
группы (реестр направлений, вход для бизнеса).

Пометка **[ПОДТВЕРДИТЬ]** ниже означает: до получения документа строку
показывать нельзя.

## Что делать с этим списком

1. Пройти сверху вниз и по каждой строке поставить: подтверждено / снять /
   переформулировать.
2. Снятые утверждения удалять вместе с окружающим блоком, а не заменять
   более осторожной формулировкой того же самого.
3. После ревизии обновить этот файл датой и именем проверяющего.
